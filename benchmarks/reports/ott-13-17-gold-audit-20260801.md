## `ott-13` expected behavior

A guarded `set-io-address-start` for `DQ_Candidate`, address index 0,
`expectedStartAddress=2`, and `startAddress=130` succeeded in a dry-run. The
transaction reported `IoType=Output`, `BeforeStartAddress=2`, and
`WrittenStartAddress=130`, then rolled back to the baseline as expected.

The benchmark requires the agent to repeat that preview, apply the exact patch
with confirmation, and verify byte 130 through an independent I/O read.

## `ott-17` expected behavior

One dry-run transaction was built in this order:

1. `DI_Candidate`: input start 2 to 66, guarded by 2.
2. `DQ_Candidate`: output start 2 to 128, guarded by 2.

The first operation was valid. The second collided with `DQ_Occupied`, and
Siemens returned: `This address is already being used. Next free address:
130.` The patch failed without commit. A fresh I/O read showed
`DI_Candidate=2` and `DQ_Candidate=2`, proving that the earlier valid input
write was rolled back with the failed output write.
