# Examples

These examples are starting points for beta testers. Replace project paths, PLC names, HMI names, and screen names with values from your own TIA Portal project.

## CLI

- `cli/read-project-info.ps1`: opens a project and prints project/device status in one interactive CLI session.
- `cli/export-plc.ps1`: exports PLC blocks to a chosen folder.

## MCP

- `mcp/open-project-and-list-devices.md`: example MCP tool call sequence for opening a project and listing devices.
- `mcp/hmi-screen-patch.md`: example safe HMI screen JSON patch flow.

## Safety

Start with read-only examples. For mutation examples, use a disposable project copy until you are comfortable with the workflow.
